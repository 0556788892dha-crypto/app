# DA Personality

Offline-first Android personality exploration app.

## Methods
- Big Five-style questionnaire (OCEAN)
- Image forced-choice preferences
- Situational choices
- MBTI-style preference dimensions (educational, not diagnostic)
- Numerology (belief/entertainment)
- Zodiac profile (belief/entertainment)
- Traditional physiognomy / face-reading (folklore only; no scientific inference from facial features)
- Combined report with confidence/evidence labels

The app does not claim to diagnose mental health or determine personality from a face. Scientific and non-scientific methods are clearly separated.
