# DA Personality

Build target: 1.2

Offline-first Android app for multi-method personality exploration.

## Current modules
- Big Five / OCEAN: 30 self-report items with visual scoring.
- HEXACO: starter 12-item six-dimension self-report.
- RIASEC: 12-item interest-style map.
- Visual preference choices.
- Situational decision patterns.
- MBTI-style preference axes.
- Numerology and zodiac as entertainment/traditional layers.
- Face module: camera or gallery input, local ML Kit face detection, landmarks/contours/classification, visual measurements, and a clearly separated folklore layer.

## Face privacy
Photos are processed locally by the app. The face module does not upload photos to a remote server.

## Face interpretation boundary
Facial measurements are presented as visual measurements only. Traditional face-reading interpretations are explicitly labeled as folklore/entertainment and are not presented as scientific personality inference or diagnosis.

## UI
- Hebrew RTL
- Small-screen friendly vertical layout
- Warm skin/peach/terracotta visual palette
- Evidence labels to distinguish research-oriented vs reflective vs entertainment methods
