# DA OSIRIS

אפליקציית Android אופליין בעברית/RTL המבוססת על Snapshots של OSIRIS Intelligence.

- אין הרשאת INTERNET לאפליקציה עצמה.
- בזמן Build ב-GitHub Actions נמשך Snapshot ציבורי מה-API של OSIRIS.
- ה-Snapshot נארז בתוך ה-APK ולכן הנתונים זמינים לאחר ההתקנה ללא רשת.
- כל feed מוגבל ל-25MB כדי לשמור על יעד חבילה של עד 400MB.
- Build חדש מרענן את ה-Snapshot.
