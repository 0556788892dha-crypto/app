# DA INFO — Release notes

## v0.7 (interim development build)
- Version code: 7; version name: 0.7.
- Refreshed the app icon artwork; the same icon is shown in Settings → About.
- About section now displays the installed app version and current knowledge-entry count.
- Added reading-comfort preference for larger article text.
- Added device-local controls to clear recent-view history or all bookmarks, with confirmation prompts.
- APK build workflow names the output `DA_INFO_v0.7.apk` and labels the artifact by version.
- Existing build validation checks JSON structure, missing fields, short entries, and duplicate titles/bodies.

## v1.0 (planned milestone)
Release as DA INFO v1.0 only when the library reaches approximately 2,000 genuine entries and the next round of usability improvements, features, and release checks is complete.

## Content quality rule
Missing information is preferable to fabricated facts. Do not inflate entry counts with templates or duplicate content.
