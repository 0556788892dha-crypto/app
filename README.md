# DA PHONES

אפליקציית קטלוג אופליין של סמארטפונים, עם חיפוש, מפרטים, דירוגים והשוואה.

## יעד מאגר הנתונים

GSMArena Phone Finder מדווח כרגע על **13,445 תוצאות**. DA PHONES נבנית כדי להגיע ליעד הזה ולהוסיף שכבת מכשירי נישה כמו QIN, UNIHERTZ ו-DOOV.

מקור היעד: https://www.gsmarena.com/m/results.php3
